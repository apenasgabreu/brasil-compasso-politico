# Créditos dos retratos

Os retratos são usados exclusivamente para identificação visual das pessoas candidatas à Presidência vinculadas aos programas. Cada imagem na interface aponta para a página-fonte. Programas sem pessoa candidata identificada no material permanecem sem retrato, em vez de receber imagem inferida. Fotografias de vices não são exibidas.
